# 🐍 Snake Game

Um jogo da cobrinha desenvolvido em Python utilizando a biblioteca Pygame.

## 🎮 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação,
estruturas de repetição, funções, listas e manipulação de eventos utilizando Python.

## 🛠️ Tecnologias utilizadas

- Python
- Pygame

## ▶️ Como executar

### 1. Instale o Python

Certifique-se de ter o Python instalado no computador.

### 2. Instale o Pygame

No terminal, execute:

```bash
pip install pygame

### 3. Faça o Download do meu repositório

Download.ZIP

### 4. Entre no arquivo que se encontra "Snake_Game.py"

Nos seus arquivos, vá até o Snake_Game.

### 5. Abra o Terminal e execute o game

Com o botão direito, abra o terminal onde se encontra o Snake_Game.py,
em seguida digite:

```bash
python3 Snake_Game.py

## Ou
